## 1. 项目简介

本项目是一个基于 ESP32-C3 的双路 RS485 DTU 固件，支持：

- 双路 RS485 半双工串口接入
- TCP / UDP / MQTT / HTTP 四种透传模式
- Web 本地配置页面
- BLE 轻量配置与维护入口
- PT1000 温度读取与校准
- OTA 在线升级
- 黑匣子事件记录和模块化日志控制

## 7. WiFi 接入

### 7.1 支持模式

- `AP`
- `STA`
- `APSTA`

### 7.2 AP 回退

STA 多次连接失败后，设备会自动回退到 AP。  
AP 名称格式：

```text
ESP32C3_DTU_XXYYZZ
```

其中 `XXYYZZ` 为设备 MAC 地址后 3 字节。  
AP 默认密码：

```text
12345678
```

## 8. RS485 接口

### 8.1 RS485-A

- UART：`UART1`
- TX：`GPIO10`
- RX：`GPIO5`
- DE/RE：`GPIO6`

### 8.2 RS485-B

- UART：`UART0`
- TX：`GPIO21`
- RX：`GPIO20`
- DE/RE：`GPIO4`

说明：

- 两路均为半双工
- 单帧最大缓存长度为 `256` 字节

## 9. 透传模式

当前支持：

- TCP
- UDP
- MQTT
- HTTP

### 9.1 数据流说明

- 串口收到普通数据后，转发到当前绑定的网络协议
- 网络收到普通数据后，回灌到指定串口
- 命令帧不会走普通透传，而是进入命令处理器

### 9.2 串口绑定

`uart_bind` 含义：

- `0`：双路都可接收网络下行
- `1`：仅 UART1
- `2`：仅 UART2

### 11.3 PT1000 校准

- `GET /api/v1/log_config`

示例：

```json

```

## 12. 特殊命令接口

命令封装格式：

```text
+++DTU_CMD:{"cmd":"xxx"}+++
```

当前支持命令：

- `read_temp`
- `calibrate`
- `status`
- `blackbox`
- `log_ctrl`
- `ota`
- `restart`

### 12.1 读取温度

```text
+++DTU_CMD:{"cmd":"read_temp"}+++
```

### 12.2 校准

```text
+++DTU_CMD:{"cmd":"calibrate","ref_ohm":1000}+++
```

### 12.3 查询状态

```text
+++DTU_CMD:{"cmd":"status"}+++
```

### 12.4 读取黑匣子

```text
+++DTU_CMD:{"cmd":"blackbox","count":20}+++
```

### 12.5 日志控制

```text
+++DTU_CMD:{"cmd":"log_ctrl","module":"ALL","enable":true}+++
```

说明：

- 当前实现只按 `enable` 做全局开/关
- `module` 字段当前仅作参数存在性检查

### 12.6 触发 OTA

```text
+++DTU_CMD:{"cmd":"ota","url":"http://192.168.1.50:8080/ESP32C3_DTU.bin"}+++
```

### 12.7 重启

```text
+++DTU_CMD:{"cmd":"restart"}+++
```

## 13. BLE 说明

当前 BLE 是轻量化维护入口，不是完整运维平台。

已实现：

- 配置摘要读取
- `key=value` 形式的单项配置写入
- 配置应用并重启
- 命令透传到 `cmd_handler`
- 最近黑匣子文本读取

当前限制：

- `ble_service_notify_status()` 仍是预留接口
- 没有完整的状态订阅推送能力

## 14. OTA 升级说明

### 14.1 升级方式

当前 OTA 采用 URL 拉包方式：

1. 将 `ESP32C3_DTU.bin` 放到 HTTP/HTTPS 服务器
2. 通过 Web 或命令接口传入固件 URL
3. 设备调用 `esp_https_ota()` 下载并写入空闲 OTA 分区
4. 下载成功后自动重启
5. 新固件启动后自动确认镜像有效

### 14.2 Web 触发

- `POST /api/v1/ota`

请求体：

```json
{"url":"http://192.168.1.50:8080/ESP32C3_DTU.bin"}
```

### 14.3 注意事项

- 应用 bin 大小必须小于单个 OTA 分区大小
- 当前实现未配置证书校验
- 设备必须能访问 URL 对应服务器

## 15. 常见排查

### 15.1 WiFi 连不上

- 检查 `wifi_ssid` / `wifi_pass`
- 查看设备是否已回退到 AP
- 读取 `/api/v1/status`
- 查看日志和黑匣子中的 WiFi 事件

### 15.2 透传无数据

- 检查 `uart1_mode` / `uart2_mode`
- 检查 `srv1_ip/srv2_ip`、端口、MQTT topic、HTTP URL
- 检查 `uart_bind`
- 查看 `/api/v1/status` 中 `net_status`

### 15.3 PT1000 读数异常

- 检查传感器接线
- 读取温度接口和原始日志
- 必要时重新执行 `calibrate`

### 15.4 OTA 失败

- 检查 URL 是否可访问
- 检查 bin 是否过大
- 查看 OTA 日志和黑匣子事件
